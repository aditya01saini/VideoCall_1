## 🚀 Features

- 📞 Real-time Video & Audio Calling
- 👥 Peer-to-Peer Connection
- 🔗 Unique Room / Call Link
- 🎙️ Microphone & Camera Access
- 🔄 Smooth Connection Handling
- ⚡ Low Latency Communication

---

## 🛠️ Tech Stack

### Frontend
- **React.js**
- **JavaScript (ES6+)**
- **HTML5 & CSS3**

### Backend / Realtime
- **WebRTC**
- **Socket.io**
- **Node.js**
- **Express.js**

### Deployment
- **Render**

---

## ⚙️ How It Works

1. User opens the application
2. A unique room / connection is created
3. WebRTC establishes peer-to-peer connection
4. Socket.io handles signaling
5. Users can communicate via live video & audio
